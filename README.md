# EEG_uch

Es un código que sirve para poder abrir y leer un dataset de EEG de 32 canales provenientes de una rata, en un experimento de neurociencia de la ansiedad. Al ejecutar el código, se obtienen gráficos como la actividad de los 32 canales, los espectrogramas, PSD, scree plot, biplot, asimismo sus respectivos residuales.
